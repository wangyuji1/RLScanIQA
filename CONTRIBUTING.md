# Contributing

Thanks for helping improve RL-ScanIQA.

1. Open an issue describing the bug, experiment, or proposed change.
2. Keep changes focused and do not commit datasets, checkpoints, credentials, review material, or personal files.
3. Add or update a small CPU test when changing core behavior.
4. Run `pytest -q` and `python -m compileall -q rl_scaniqa scripts` before submitting a pull request.
5. Clearly distinguish newly reproduced results from values transcribed from the paper.

By contributing, you confirm that you have the right to submit the material. A project-wide open-source license has not yet been selected.
